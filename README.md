# Edu — School Management System

A school-focused student management and academic support platform built with React, TypeScript, Vite and Supabase.

## Core modules
- Role-based access: Admin, Teacher, Advisor and Student
- Students: class, section, roll number and academic year
- Teachers and class assignments
- Subjects, academic records, marks and attendance
- Risk assessments and intervention tracking

## Setup
See `docs/SETUP.md`. Never expose a Supabase service-role key in the browser.
